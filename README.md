# JSK Supporters
تطبيق Android لمتابعة شبيبة القبائل بواجهة عربية وألوان الأخضر والأصفر.

## الوظائف
- صفحة رئيسية عربية.
- متابعة الأخبار والمباريات والنتائج عبر صفحات Winwin.
- إضافة مباراة يدوياً مع تذكير قبل ساعة، عند الانطلاق، وتذكير تقديري بعد ساعتين ونصف.
- حفظ آخر مباراة محلياً.
- GitHub Actions لبناء APK تجريبي تلقائياً.

## البناء محلياً
افتح المشروع في Android Studio مع JDK 17 و Android SDK 35، ثم Build > Build APK(s).

## حدود النسخة الأولية
لا توجد حالياً واجهة API موثقة أو مزامنة آلية للمواعيد والنتائج. بيانات Winwin تتطلب اتصال إنترنت. تنبيه نهاية المباراة تقديري وليس تأكيداً للنتيجة أو صافرة النهاية. اسمح بإشعارات التطبيق، وقد تؤثر إعدادات توفير الطاقة في توقيت التنبيهات.
